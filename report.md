- Debian 12 x86-64, Python 3.11.2, Node 22.22.3, approximately 3.8 GiB RAM.
- No system FFmpeg/ffprobe, Blender, Chromium, espeak, festival, nvidia-smi, or detectable GPU tools in PATH. No Pillow, NumPy, SciPy, Cairo, OpenCV, PyTorch, or Playwright in the system Python. No globally installed Remotion or headless browser package.
- No environment variables for external TTS or generative API keys were detected; GitHub credentials were not tested or used as a generative API. Network access is limited to configured hosts, so arbitrary API endpoints were not probed.
- Plan: install locally available packages and a static FFmpeg binary from an allowed package registry; render procedural 2D artwork with Pillow, with a selected Arena speech voice if available. No Blender, 3D model, stock imagery, or external music is assumed.

## Production setup
- Installed Python packages Pillow, NumPy, SciPy, aggdraw, imageio-ffmpeg and fonttools in the local virtual environment; FFmpeg came from imageio-ffmpeg, ffprobe from the npm `@ffprobe-installer` package. Inter Bold and JetBrains Mono Bold came from the `@fontsource` npm packages and were converted from WOFF to TTF with fontTools. Both are open-source typefaces.
- Arena speech generation supplied one selected masculine narration voice (voice-00); nine actual takes were generated. No external TTS API credentials, stock footage, generative image models, Remotion, browser, Blender, or GPU rendering were used. Artwork is original procedural layered 2D, not 3D.
- Every spoken line is time-stretched with FFmpeg `atempo` to fit its window, without changing the written script. Actual original and placed durations are in `assets/audio_timing.json`. Speech received high-pass filtering and light compression; a dedicated de-esser was not available in this chain.
- Music, beat sounds and accents are synthesized with Python/NumPy, mixed with narration, then loudness-normalized using FFmpeg. The score is ducked by approximately 9 dB during narration. All timings come from the `src/bpm_clock.py` master clock; irregular beats use a seeded random generator. The final calm sequence is phase-aligned to land a beat at 59.7 seconds.
- Word highlights and SRT timings use weighted word-duration estimates based on the real time-fitted takes. No forced aligner or speech timestamps were available, so exact word-level synchronization is not guaranteed.
- The 540×960 preview is the procedural master; the final is upscaled to 1080×1920, not natively rendered at 1080p. This preserves timing but cannot add native 1080p detail.

## Actual output and QA
- **Final:** `out/final_heart_5x_short.mp4`, exactly 60.000 seconds, 1,800 decoded frames, constant 30 fps, 1080×1920, H.264 High, yuv420p, video bitrate 11.961 Mb/s (container 12.160 Mb/s). AAC-LC stereo, 48 kHz, measured 190.8 kb/s. Faststart verified: `moov` precedes `mdat`.
- **Preview:** `out/preview.mp4`, exactly 60.000 seconds, 540×960, 30 fps, H.264 High and AAC stereo. Its real decoded frames were checked before final export.
- **SRT:** `out/captions.srt` contains the supplied narration text, divided into readable phrase cues. Burned captions highlight estimated active words; they are not verified against phoneme timestamps.
- Full final file decode using FFmpeg completed without errors. Final audio measured by FFmpeg `ebur128`: integrated **-14.9 LUFS**, true peak **-1.2 dBTP**, LRA **2.4 LU**. The narration was mixed above the ducked bed, but no human listening or independent intelligibility assessment was possible in this run.
- Inspected decoded frames at each scene boundary and mid-scene, including the first and last frames. Layout is designed around the requested safe region; no formal pixel-level text bounding-box audit was performed. Labels and major captions were reviewed on the decoded contact sheet. Small ancillary data labels may be difficult to read on a phone.
- First/last composition is matched by a short dissolve back to the opening design; decoded 64×114 grayscale first/last frame mean absolute difference was **0.255/255** due to encoding. Last sound beat is scheduled at 59.7 s; the opening beat is at 0.3 s.
- No full-frame flashing is intentionally authored. A scan of all 1,800 decoded frames downsampled to 64×114 found no frame-to-frame mean luminance change greater than 20/255; the maximum was 1.96/255. This simple check is not a formal photosensitivity certification. The heartbeat pulse is capped at 2.8%; the hook's one-time camera punch is separate.
- Master BPM keyframes and 46 sampled irregular intervals passed a small programmatic assertion check; intervals use deterministic ±40% jitter. Scene boundaries are exact. The requested special dissolves, zoom-throughs, brain POV, realistic 3D camera orbit, detailed coronary macro, and elaborate SFX are **not fully realized**: the fallback uses cuts, restrained illustration motion, diagrammatic transitions, and synthesized accents instead. It is more diagrammatic than the requested cinematic medical render and may feel less dynamic than the brief.
- Baseline 70 is an example, the 190 estimate is age-dependent, and 350 is a hypothetical. The filling bars are illustrative, not measured data. The supplied phrase “Your brain notices first” is a narrative simplification, not a universally predictable order of symptoms; symptom timing and severity vary.
- Initial final-frame extraction at 59.9667 seconds failed because that seek was fractionally past the timestamp of the last frame; repeating at 59.9666 seconds succeeded. No final export failed. The existing repository workshop test suite had **12 passing and 1 failing**: its offline skill-runtime test expects the pinned HyperFrames runtime and recommends `npm ci`. This production did not use HyperFrames, and the failure concerns the pre-existing workshop setup, not this file's encode. No formal automated test verifies narration word alignment, full safe-zone compliance, or artistic quality.
